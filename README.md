# Anlamsız Türkçe Cümle Üreticisi

## Bu Repo Nedir?

Sevgili okuyucu, bu repository sadece bir kod deposu değildir. Bu, insanlığın anlamsızlık arayışında attığı en büyük adımdır. Bilimsel olarak kanıtlanmış, peer-reviewed (hayali dergilerde) ve Nobel ödülü adayı (hayali komitelerce) bir projedir.

Bu araç, tamamen rastgele ama gramer açısından kusursuz Türkçe cümleler üretir. Cümleler o kadar anlamsızdır ki, anlam aramak beyin hücrelerinizi yok eder. Bu yüzden önerilir: anlam aramayın, sadece okuyun ve gülün (ciddiyetle).

## Nasıl Çalışır?

1. Python 3 kurun (çünkü modern olmak zorundayız).
2. `python uretici.py` komutunu çalıştırın.
3. 5 adet anlamsız cümle üretildiğini izleyin.
4. Hayatınızın anlamını sorgulayın.

## Örnek Çıktı

```
=== Anlamsız Türkçe Cümle Üreticisi ===
Bu program bilimsel olarak kanıtlanmış anlamsızlık üretir.

1. Kediler sonsuz döngüde dans ediyor.
2. Bürokratlar ciddiyetle felsefe yapıyor.
3. Çaydanlıklar rastgele uyuyor.
```

## Bilimsel Temel

Bu proje, kuantum rastgeleliği ve Türkçe dilbilgisi kurallarını birleştirerek anlamsızlığı maksimize eder. Her çalıştırışta farklı sonuçlar verir çünkü evren böyledir.
